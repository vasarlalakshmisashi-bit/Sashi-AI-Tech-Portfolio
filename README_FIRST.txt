SASHI AI & TECH PORTFOLIO — ROBOT UPGRADE

1. Keep a backup of your current project.
2. Copy the three files from this ZIP's app folder into your existing project's app folder:
   index.html
   style.css
   script.js
3. Choose Replace when Windows asks. These are complete replacement files.
4. From the project root, run:
   python -m http.server 8000 --bind 127.0.0.1 --directory app
5. Open http://127.0.0.1:8000

The robot is built with CSS shapes, not a downloaded 3D model. It has a full-body standing design, idle movement, waving arm and mouth movement while speech is playing. The closing-message button plays “This is my portfolio. Thank you!” when clicked.
